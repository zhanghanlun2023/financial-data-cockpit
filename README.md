# 财务数据驾驶舱（年度 TB 版）

基于 2020—2025 年年度 TB 建立的 Streamlit 财务分析驾驶舱。

## 看板内容

- 集团总览：资产、负债、收入、利润、现金流和资产负债率
- 年度趋势：集团审定口径的年度变化与同比
- 公司对标：同年度公司经营矩阵和指标排名
- 科目结构：按主体、报表查看大额科目
- 明细查询：按年度、主体、报表和关键词筛选并下载

## 数据口径

集团指标分别取各年度 TB 中的“审定数”或“抵销/调整后金额”，不使用公司简单加总。金额由元换算为万元。所有者权益按“资产总额－负债总额”计算。

生成后的数据位于 `data` 目录：

- `tb_detail.csv`：年度、报表、科目、主体的标准化长表
- `tb_summary.csv`：集团与公司核心指标表
- `tb_quality.json`：年度来源列、覆盖情况和质量检查结果

## 更新 TB

直接整理当前数据目录中的 TB：

```powershell
python tb_parser.py "data\2020年-2025年TB.xls" --output data
```

全自动模式下，可把名称含 `TB` 的 `.xls` 文件放入 `待处理数据`。定时任务会校验、生成看板数据、备份旧数据、推送 GitHub，并触发 Streamlit 自动重新部署。

## 本地运行

```powershell
python -m streamlit run app.py
```
